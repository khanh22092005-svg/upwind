## Making a new episode

The project `_production/upwind-are/` is a template for more Part 1 tips: change the lines in
`tools/build_voice.py`, re-record the Vietnamese narration in Vbee (one take, about 1s pause
between lines) and re-render. See `_production/upwind-are/Progress.md` for the commands.
